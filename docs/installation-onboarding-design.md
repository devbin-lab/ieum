# 설치와 첫 실행 설계

## 조사와 적용

공식 제품 안내와 Windows UI 지침을 기준으로 설치와 앱의 첫 실행을 나눴다. 표의 적용 내용은 이음의 설계 결정이며 각 제품 화면의 복제는 아니다.

| [VS Code Windows 설치](https://code.visualstudio.com/docs/setup/windows) | 사용자별 설치, 관리자 권한 없는 설치 위치, 별도 ZIP 배포, Inno Setup | 현재 Windows 계정에 설치하고 시작 메뉴·바탕화면 바로가기를 제공 |

## 기존 구조

- `Ieum-Windows-x64.exe`는 내장 ZIP을 `%LOCALAPPDATA%\Ieum\builds\<빌드 ID>`에 풀고 앱을 실행하는 배포 런처다. 설치 등록과 지속적인 시작 메뉴 바로가기는 없었다.
- 앱 업데이트는 포터블 EXE의 SHA-256을 검증하고 다음 실행에 적용한다. 설치형 배포도 이 업데이트 경로를 사용해야 한다.
- `ProjectGate`가 GitHub 인증·인증 복원·프로젝트 생성·참여·최근 프로젝트 복원을 담당한다. 첫 화면에는 로그인·인증·프로젝트 설정이 한 흐름에 모여 있었다.
- 화면 설정은 프로젝트 데이터와 별도의 `app-preferences.json`에 저장한다. 기존 사용자의 설정과 프로젝트는 새 설치나 온보딩으로 초기화하지 않는다.

## 사용자 흐름

1. `Ieum-Setup-x64.exe` 실행: 언어 선택 → 설치 위치 → 바로가기 옵션 → 설치 → 이음 실행.
2. 새 사용자 첫 실행: 환영 → 언어·화면 모드·포인트 컬러 → 준비 완료.
3. 시작 화면: GitHub 로그인 → 프로젝트 만들기 또는 참여. 기존 계정은 인증 복원과 최근 프로젝트 열기를 계속 사용한다.
4. 초기 설정을 완료하거나 명시적으로 건너뛰면 재실행 시 반복하지 않는다. 개인 설정에서 화면·언어를 다시 변경할 수 있다.

## 설치·업데이트 경계

- 기본 설치 위치는 `%LOCALAPPDATA%\Programs\Ieum`이며 관리자 권한을 요구하지 않는다.
- 시작 메뉴와 선택한 바탕화면 바로가기는 설치 위치의 안정된 런처를 가리킨다. 빌드마다 바뀌는 앱 실행 경로를 바로가기에 넣지 않는다.
- 기존 `Ieum-Windows-x64.exe`와 ZIP은 포터블 사용과 기존 업데이트 호환을 위해 함께 생성한다.
- 제거는 설치된 앱과 바로가기를 대상으로 한다. 프로젝트 DB, 개인 설정, 자격 증명과 팀의 GitHub 데이터는 삭제하지 않는다.
- 설치 과정에 GitHub 로그인이나 팀 데이터 생성을 넣지 않는다. 앱에서 사용자가 실제 인증·프로젝트 동작을 수행한다.

## 화면 원칙

- 기존 회색 타이틀바·아이콘바와 메인뷰의 둥근 모서리를 유지한다.
- 단계마다 주요 버튼은 하나로 제한하고 뒤로 가기·건너뛰기는 보조 동작으로 둔다.
- 실제 이음 아이콘을 사용한다. 데모 프로젝트와 샘플 작업을 시작 화면의 데이터로 생성하지 않는다.
- 한국어·영어와 라이트·다크·시스템 테마를 제공한다. 테마와 언어 변경은 기존 설정 화면에서도 이어진다.
- 최소 창 크기 480×420과 확대 글꼴에서 내용을 스크롤할 수 있도록 구성한다.

## 검증 기준

설치 패키지 컴파일, 격리된 경로의 설치 파일·바로가기·제거 검사, 초기 설정 저장·재시작·기존 설정 호환, 로그인·프로젝트 진입 회귀, 좁은 창과 확대 글꼴 검사 및 Windows Release 빌드를 확인한다. 실제 사용자 계정에 설치하거나 프로젝트를 생성하는 수용 검증은 사용자가 진행한다.

## 검증 결과 · 2026-10-10

- `flutter analyze --no-pub`: 오류와 경고 없음.
- 초기 설정·환경 설정·GitHub 인증·프로젝트 진입 관련 회귀 테스트 및 시스템 테마 전환 테스트 통과.
- 격리된 설치 검사 24개, 런처 검사 27개 통과. 실행 파일이 잠긴 경우 재설치·제거를 중단하며 강제 종료하지 않는 동작도 포함한다.
- 실제 Flutter 위젯으로 라이트·다크 화면과 좁은 창을 렌더링하고 확인했다.
- Windows Release 빌드와 설치 패키지 컴파일 성공. 앱과 설치 파일의 버전은 `1.0.0`이다.
- 최종 배포 폴더: `dist/windows/20261010-181341`. 설치형 EXE, 포터블 EXE와 ZIP의 SHA-256이 모두 일치한다. ZIP의 실행 파일·앱 코드·브랜드 아이콘은 최신 Release 빌드와 일치한다.
- 배포 ZIP에는 프로젝트 DB, 개인 설정, 로그나 샘플 데이터를 포함하지 않는다.

이번 검증은 실제 사용자 프로필에 설치하거나 GitHub 계정으로 로그인하지 않았다. 실제 설치와 프로젝트 사용 검증은 이 설치 파일로 진행할 수 있다. 게시된 배포 파일은 GitHub 1.0.0 릴리즈에서 확인한다.
