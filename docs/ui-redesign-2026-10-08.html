탭마다 다른 화면을 하나의 작업 공간으로

색을 바꾸는 수준을 넘어 탐색, 보기 전환, 필터, 실행 동작의 위치를 통일했습니다. 아이콘바·타이틀바의 회색 배경과 메인뷰 외곽 16px 라운드는 기존 설정을 유지합니다.

현재 구성에서 해결한 문제

정보보다 큰 장식

작업 위의 큰 현황 카드들이 보드 공간을 차지했습니다. 상태별 수치를 한 줄 요약으로 바꾸고 작업 열을 화면 높이에 맞췄습니다.

서로 다른 목적의 버튼 혼합

탐색·필터·생성·상태 변경·삭제가 같은 강조 수준에 있었습니다. 범위 탭, 보기 선택, 필터, 주요 동작과 관리 메뉴를 분리했습니다.

탭마다 다른 간격과 배치

제목·본문·카드·입력 요소에 공통 컴포넌트와 간격 기준을 적용했습니다. 긴 목록은 각 콘텐츠 영역에서 스크롤합니다.
