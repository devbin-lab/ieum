# 이음 1.0.0

GitHub 저장소를 팀 데이터의 기준으로 사용하는 Windows 데스크톱 작업 공간입니다.
작업·일정·기록·자료·팀 링크를 하나의 프로젝트에서 관리합니다.

## 포함된 기능

- 작업 목록과 칸반: 확인중·진행중·검토중·완료·보류·드랍, 우선순위·상단 고정·검색·필터·보관·삭제.
- 담당자 전달과 잠금: 받을 파트·작업자와 목적을 지정하고 최종 확인합니다. 잠금 없이 함께 편집하거나 지정한 담당자만 수정하도록 설정할 수 있습니다.
- 일정: 시작일~마감일을 이어진 기간 막대로 표시하고 작업 상태 색상을 적용합니다. 오늘 날짜는 포인트 컬러와 별도로 빨간색으로 표시합니다.
- 알림과 타임라인: 알림 목록·세부 내용, 마지막으로 사용한 작업 보기로 이동, 프로젝트 전체 변경 기록 확인.
- 참여자와 파트 관리: 신규 프로젝트는 빈 파트 목록으로 시작합니다. 관리 권한과 작업 배정을 구분합니다.
- 작업 자료: Markdown 미리보기, HTTPS 링크·파일 첨부, 기본 파일당 50MB 및 관리자의 한도 설정.
- 디자인과 언어: 라이트·다크 모드, 포인트 컬러와 흑백 자동 전환, 한국어·영어.
- 팀 바로가기: 추천 도구 목록, 직접 팀 URL 등록, 사이트 아이콘 자동 탐색, 검색·즐겨찾기. GitHub 팀 링크를 자동 등록하지 않습니다.
- GitHub 동기화: 개인 SQLite 저장, 작업별 커밋·PR·검증·통합, 전송 복구 기록과 경고 확인 상태 보존.
- Windows 네트워크 연결: 시스템·사용자 프록시 및 인증서 설정을 적용합니다.

작업 단계 자동화와 별도 반려 기능은 포함하지 않습니다. 코멘트와 담당자 전달을 사용합니다.

## 설치와 업데이트

1. `Ieum-Windows-x64.exe`를 실행합니다. 개발 도구 설치는 필요하지 않습니다.
2. ZIP을 사용할 경우 전체 파일을 풀고 `ieum_flutter.exe`를 실행합니다.
3. GitHub 로그인 후 프로젝트를 만들거나 참여합니다.

기존 프로젝트 DB와 계정 정보를 배포 파일에 넣지 않습니다. 기존 로컬 데이터는 그대로 사용합니다.
설정의 앱 정보에서 업데이트를 확인할 수 있으며, 정식 업데이트 대상은 `v1.0.0`입니다.
`SHA256SUMS.txt`의 해시로 다운로드한 EXE·ZIP을 확인할 수 있습니다.

## 이전 버전

기존 20개 릴리즈의 변경 내역과 배포 파일 46개는 [Beta 통합 릴리즈](https://github.com/devbin-lab/ieum/releases/tag/beta)에 보존합니다.
버전별 파일명을 사용하며, 원래 버전의 Git 태그와 소스 이력은 유지합니다.

## 검증 범위

코드 정적 분석과 현행 UI 회귀 테스트 53개를 확인했습니다. Windows Release 빌드·배포 파일과 실행 시작을 확인한 뒤 게시합니다.
팀 계정과 실제 프로젝트를 사용하는 수용 검증은 별도로 수행해야 합니다.

전체 과거 테스트에는 삭제된 자동화·3단계 워크플로와 이전 UI를 전제로 한 사례가 남아 있습니다.
최초 전체 실행은 450개 통과·152개 실패·1개 건너뛰기였으며, 실제 참여자 필터의 글꼴 확대 시 오버플로와 현행 UI 테스트 기준을 정리해 관련 53개를 재검증했습니다.
과거 워크플로 테스트 정비가 남아 있으므로 전체 테스트와 Linux CI가 모두 통과한 릴리즈로 표시하지 않습니다.
이번 정식 배포 파일은 Windows x64용입니다. 이전 Linux 배포 파일은 Beta 보관본에서 확인할 수 있습니다.
