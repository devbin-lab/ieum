# 이음 1.0.0

GitHub 저장소를 팀 데이터의 기준으로 사용하는 Windows 데스크톱 작업 공간입니다.
작업·일정·기록·자료·팀 링크를 하나의 프로젝트에서 관리합니다.

## 포함된 기능

- 작업 목록과 칸반: 확인중·진행중·검토중·완료·보류·드랍, 우선순위·상단 고정·검색·필터·보관·삭제. 목록은 기본 54px 행으로 구성하고 날짜를 기간 열로 묶었습니다. 부가 작업 처리는 더보기 메뉴에서 실행합니다.
- 담당자 전달과 잠금: 받을 파트·작업자와 목적을 지정하고 최종 확인합니다. 잠금 없이 함께 편집하거나 지정한 담당자만 수정하도록 설정할 수 있습니다.
- 일정: 시작일~마감일을 이어진 기간 막대로 표시하고 작업 상태 색상을 적용합니다. 오늘 날짜는 포인트 컬러와 별도로 빨간색으로 표시합니다. 일정 상세의 **작업으로 이동**을 누르면 마지막 목록·보드 보기에서 같은 작업을 열고, 목록의 해당 페이지와 행을 찾아줍니다.
- 알림과 타임라인: 알림 목록·세부 내용, 마지막으로 사용한 작업 보기로 이동, 프로젝트 전체 변경 기록 확인.
- 참여자와 파트 관리: 신규 프로젝트는 빈 파트 목록으로 시작합니다. 관리 권한과 작업 배정을 구분합니다.
- 작업 자료: Markdown 미리보기, HTTPS 링크·파일 첨부, 기본 파일당 50MB 및 관리자의 한도 설정.
- 디자인과 언어: 라이트·다크·시스템 모드, 포인트 컬러와 흑백 자동 전환, 한국어·영어. 첫 실행에서 언어와 디자인을 설정할 수 있습니다.
- 팀 바로가기: 추천 도구 목록, 직접 팀 URL 등록, 사이트 아이콘 자동 탐색, 검색·즐겨찾기. GitHub 팀 링크를 자동 등록하지 않습니다.
- GitHub 동기화: 개인 SQLite 저장, 작업별 커밋·PR·검증·통합, 전송 복구 기록과 경고 확인 상태 보존.
- Windows 네트워크 연결: 시스템·사용자 프록시 및 인증서 설정을 적용합니다.
- Discord 채널 알림: 채널별 웹훅, 배정·전달·상태 변경·완료 알림, 개인·파트 담당자 멘션. 별도 서버나 공용 봇 없이 변경한 PC에서 GitHub 반영 후 전송합니다.
- Discord 연결 보안: Windows 자격 증명 보관소, 승인 기기에 대한 암호화 배포, 전송 이력과 재시도·수신 미확정 상태 관리.
- 유지보수: 사용하지 않는 자동화 화면·API 제거, 프로젝트 정보 캐시와 알림 대기열 조회 최적화, 이전 설정 호환 유지.

작업 단계 자동화와 별도 반려 기능은 포함하지 않습니다. 코멘트와 담당자 전달을 사용합니다.

## 설치와 업데이트

1. 권장: **`Ieum-Setup-x64.exe`**를 실행해 설치합니다. 현재 Windows 계정에 설치하며 관리자 권한이 필요하지 않습니다. 시작 메뉴 바로가기를 만들고 바탕화면 바로가기를 선택할 수 있습니다.
2. 설치 없이 사용하려면 `Ieum-Windows-x64.exe`를 실행합니다. ZIP을 사용할 경우 전체 파일을 풀고 `ieum_flutter.exe`를 실행합니다. 개발 도구 설치는 필요하지 않습니다.
3. 처음 실행하면 언어·화면 모드·포인트 컬러를 설정한 뒤 GitHub로 로그인하고 프로젝트를 만들거나 참여합니다. 기존 사용자의 설정과 프로젝트는 유지됩니다.

기존 프로젝트 DB와 계정 정보를 배포 파일에 넣지 않습니다. 기존 로컬 데이터는 그대로 사용합니다.
설정의 앱 정보에서 업데이트를 확인할 수 있으며, 정식 업데이트 대상은 `v1.0.0`입니다.
프로그램을 제거해도 프로젝트와 개인 설정은 유지됩니다. `SHA256SUMS.txt`의 해시로 설치형·포터블 EXE와 ZIP을 확인할 수 있습니다.

이번 배포의 빌드 ID는 **`20261010-212240`**입니다.

## 이전 버전

기존 20개 릴리즈의 변경 내역과 배포 파일 46개는 [Beta 통합 릴리즈](https://github.com/devbin-lab/ieum/releases/tag/beta)에 보존합니다.
버전별 파일명과 변경 내역을 유지하고, 소스는 커밋 링크로 확인할 수 있습니다. 공개 태그는 `beta`와 `v1.0.0`만 사용합니다. 이전 태그와 커밋의 대응표는 Beta의 `Legacy-tag-map.json`에 보관합니다.

## 검증 범위

이전 기반 버전의 Discord·프로젝트 캐시·설정 복원·작업 삭제 관련 회귀 테스트 78개에 이어, 이번 목록·일정 변경 관련 테스트 24개와 실제 위젯 렌더링 검사를 통과했습니다. 전체 코드 정적 분석에서 문제 없음을 확인했습니다. Windows Release를 빌드하고 배포 파일의 필수 구성·버전·SHA-256을 검사했으며 ZIP의 실행 파일과 앱 코드가 최신 빌드와 일치함을 확인했습니다.

실제 팀 프로젝트 조작과 Discord 메시지 발송을 포함한 사용 검증은 이번 배포 검사에 포함하지 않았습니다. 전체 테스트나 Linux CI 통과를 주장하지 않습니다. 이번 정식 배포 파일은 Windows x64용이며, 이전 Linux 배포 파일은 Beta 보관본에서 확인할 수 있습니다.
