# 작업 상단 고정

작업 목록·좁은 창 목록·칸반 카드의 핀 버튼, 작업 상세의 상단에 고정 버튼으로 설정·해제한다. 고정 작업은 일반 작업보다 앞에 표시하며, 고정 작업끼리는 높음 → 보통 → 낮음 순으로 정렬한다. 같은 우선순위는 사용자가 선택한 정렬과 작업 ID로 순서를 결정한다. 칸반에서는 각 상태 열의 상단에 고정한다. 검색·필터는 유지하고 고정 시 목록의 첫 페이지로 이동한다.

고정 상태는 작업 데이터에 저장해 GitHub에도 동기화한다. 기존 작업에서 필드가 없으면 고정하지 않은 상태로 읽는다. 내용 수정 시 고정 상태를 보존하며, 고정 변경은 별도 버전·이력으로 기록한다. 잠금 담당자만 잠긴 작업의 고정을 바꿀 수 있다. 고정은 완료된 작업의 내용을 수정할 수 있게 하지 않으며 보관·삭제된 작업에서는 변경하지 않는다. 새 잠금과 미통합 고정 변경이 겹치면 충돌을 보존한다.

고정 기능 검사 7개 통과: 이전 데이터 호환, 버전·저장·해제, 우선순위 정렬, 잠금 및 완료·보관·삭제 정책, 잠금 충돌, 모의 GitHub 제출과 통합, 목록·칸반·좁은 창에서 버튼 및 정렬. 기존 잠금·삭제·앱 화면 검사도 통과했다. 정적 분석 No issues found. 실제 프로젝트에 테스트 작업을 추가하지 않는다.
