# 작업 삭제 구현 · 2026-10-08

`deletedAt`의 빈 기본값으로 기존 작업 JSON을 읽는다. 삭제는 별도 버전과 UTC 시각으로 원자적으로 저장한다. 표시 목록에서 제외하지만 GitHub 제출과 기준본에는 남겨 오래된 통합본이 작업을 다시 나타나게 하지 못하도록 한다. 삭제한 작업의 알림도 정리한다. 삭제 후 수정·전달·복원은 공통 검증기가 거절하며 삭제와 숨겨진 내용 수정을 함께 제출할 수 없다.
