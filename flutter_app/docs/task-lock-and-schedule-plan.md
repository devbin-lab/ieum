# 일정 기간과 수동 작업 잠금

## 확인한 문제
- 달력과 날짜별 목록은 마감일만 사용하고 타임라인만 지정일을 포함한다.
- 수동 전달과 저장된 자동화 경로가 함께 실행되어 반려와 수신 권한을 혼용한다.
- 공유 검증과 병합은 담당자 변경을 원자적으로 처리하지만 별도 작업 잠금은 없다.

## 구현
1. 지정일~마감일 양 끝을 포함하는 일정으로 달력/목록을 통일한다. 표시 월의 42일만 계산한다.
2. 자동화 실행, 자동화 편집 화면, 반려 동작을 제거한다. 기존 저장 자료는 읽을 수 있도록 남기되 실행하지 않는다. 상태는 확인중/진행중/완료로 유지한다.
3. 잠금 담당자를 작업에 저장한다. 잠그기/해제/잠금 전달은 버전 검증과 GitHub의 동일 정책 검증을 거친다. 잠금 담당자만 내용, 상태, 전달, 삭제, 보관을 변경한다. 다른 활성 참여자는 열람과 코멘트만 가능하다.
4. 잠근 채 전달은 특정 활성 담당자 한 명에게만 허용한다. 수신자에게 잠금이 이전되고 이전 담당자는 수정할 수 없다. 잠금 해제는 현재 잠금 담당자만 허용한다.
5. 코멘트는 별도 변경으로 저장하고 작성자를 검증한다. 동시 코멘트는 ID로 합치고 기존 코멘트 수정/삭제를 금지한다. 코멘트 100개, 각 2000자 상한을 명시해 무제한 데이터 증가를 방지한다.
6. 기존 데이터에 새 필드가 없으면 잠금 없음/코멘트 없음으로 읽는다. 실 프로젝트에 테스트 작업을 만들지 않는다.
